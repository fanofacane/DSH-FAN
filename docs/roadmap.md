# DSH Fan 路线图

当前只维护 SwiftUI iOS 客户端。功能状态与验证限制见 [ios-native-parity.md](design/ios-native-parity.md)，按顺序执行的任务与硬规则见 [ios-codex-tasks.md](design/ios-codex-tasks.md)。参考实现 DSH Go 的 Flutter / 安卓源码见上游 DSH Go 仓库。

长期方向：**手机端助手**（用 iOS 公开系统能力替用户办事）与**可交互的情绪伴侣**（以桌宠为起点的陪伴角色）。当前功能仍较基础。

T1–T15 已完成相应验收；真实账号回跳、真机系统集成等未验证范围仍在对照表中保留。T9 终端与 T17 WebRTC 暂缓，T16 插件安装 / 市场取消。插件管理器保持禁用，未来方案 A 仅考虑随 App 打包，后台接口未设计。

T18–T23、会话共享上下文 / 动作协议和大界面拆分（B–D）已完成。阶段 E 的正式构建输入、安卓遗留、Apple 目录、历史归档与中英文仓库地图也已整理。E1 已完成全量验收；按用户后续指示，E2–E5 先完成结构，只做工程生成与静态核对，后续仍需安排运行时重建及新结构的完整验收。配套市场、托管分享、论坛、原作者官网不属于 iOS 产品功能。
