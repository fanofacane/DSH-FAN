# dsh-Go 仓库红线
真源为当前目标分支的 AGENTS.md、README.md 全文；本表非穷举。严重度属本技能政策，仓库文本仅定义义务。

## 1. 源码与生成物分离｜❌
只改真源，不手改 `apple/DSH.xcodeproj`、SDK 类型及技能生成物；工程改生成器后运行，文案维护中英文 xcstrings，SDK 改 messages/source.json、schema / 模板或 skill 输入后运行对应生成器。生成物与输入不一致即阻断。

## 2. 引擎补丁与 pins 同步｜❌
`runtime/patches/` 的补丁文件与 `pins.json` 必须同步；不手改正被补丁覆盖的 vendor 产物；升级引擎版本时补丁必须仍可应用。查 pins、patch 内容、runtime 启动路径。

## 3. 桥接协议只有一个真源｜❌
`/dsh-go/v1/*` 路由的请求/响应形状、错误码（如 `unavailable`）以 `runtime/bridge/dsh-go-bridge/` 为准；App 端（`apple/Modules/DSHClient`、`apple/App`）只消费，不另立平行定义。改一端必须同步另一端与测试。

## 4. 危险操作以主机回答为准｜❌
删除会话、权限、凭据这类操作：能力/失败以主机/引擎实际回答为准，不用本地推断冒充；失败给稳定错误码，不静默吞。能力未知不得当作"不支持"。

## 5. 状态所有者唯一｜⚠️/❌
SwiftUI / Observation 状态的生命周期、mux generation、连接对象归属清晰；异步回调不复活已销毁状态；切主机/换连接时旧对象必须退休。

## 6. 双语文案同步｜⚠️
英文 key 与简体中文 xcstrings 同步；README 中英两版同步；语义等价而非逐字翻译。

## 7. 凭据与隐私｜❌
不记录/回显/持久化完整 API key、token、cookie、登录态；诊断包与日志外发前人工检查；自动打码不是保证。

## 8. Git 安全｜❌
只暂存明确路径，不用 `git add .`/`-A`；不 stash 藏他人改动；不 force push main 或重写共享历史，除非用户明确要求；重写后必须重建受影响的分支与 PR；未经要求不 commit/push/tag/release。

## 9. 构建与真机契约｜⚠️/❌
iOS 工程通过生成器维护；构建与测试固定 iPhone 18 Pro 的显式设备 ID，不操作 WOO UI Review。手机系统操作、通知、后台期限与安装更新须真机验证，模拟器不能替代。声称跑过不存在的命令即阻断。

## 10. 范围纪律｜⚠️/❌
一 PR 一主题；不夹带无关格式化、依赖升级、上游同步树、本地配置；越界到不可可靠审查/回滚按 ❌，少量可独立剔除 churn 按 ⚠️。

## 11. App Store 约束｜❌
不恢复插件安装、市场或包管理入口；保留每次启动禁用插件管理器的补丁，store 冒烟通过；新增系统 API 同步隐私清单。方案 A 当前只允许本地全部关闭门控，后台接口先问用户。
